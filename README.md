# apnamap-packs

अपना मैप (Android app) के ज़िला data packs। `index.json` में सूची (आकार, sha256, बनने की तारीख़) है; हर ज़िले की
`.sqlite.gz` file इस repo की release "packs" में है।

स्रोत: OpenStreetMap / Overture Maps (ODbL; घर: Google Open Buildings, Microsoft ML Buildings), LGD,
Survey of India, sansad.in, India Post, ज़िलों की सरकारी websites, Wikipedia।
